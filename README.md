# draw-music
The music drawing device
This will hold a pcb that will have two sider one that controls volume and one that controls frequency making it so that when connected at 90 deg they can act like a coordinate system making it so when you slide them to find a coordinate on the grid it will emulate a sound. The pcb will be held in a 3d printed case so it can also hold paper and have the 2 sliders conected where a pen can rest so when you draw on the paper it makes music.
